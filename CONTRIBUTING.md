# Contributing

These guidelines apply to every repository under github.com/erancha. GitHub shows this page on each
repository that has no `CONTRIBUTING.md` of its own.

- **Issues** follow the label pack in `docs/labels.md`: what each label means, how an issue is
  labelled, and how the pack reaches a repository.
- **An issue states one gap:** what the system should do and does not yet. The opening paragraph
  gives the current state, the next gives the goal in the "should" voice, and a `Done when` list
  closes it with observable conditions.
- **Commits** lead with the outcome the change achieves, in the imperative, and explain the previous
  behavior before the new one when the diff does not make the reason obvious.
